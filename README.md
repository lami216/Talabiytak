# Product Image Manager — Phase One
Production-oriented asynchronous FastAPI application for extracting Excel images, storing them in ImageKit, and managing searchable Arabic product metadata in MongoDB Atlas. Persistence uses the official PyMongo `AsyncMongoClient`. The primary guide is [README_AR.md](README_AR.md); deployment details are in [DEPLOYMENT.md](DEPLOYMENT.md).

Phase Two order creation and Excel/PDF export are intentionally absent.
